# 🎮 Gaming Store

Django asosida yozilgan onlayn o'yinlar do'koni. Amaliyot loyihasi sifatida yaratilgan — o'yin sotib olish, kutubxona, chegirmalar, sharhlar va ko'p tilli qo'llab-quvvatlash kabi funksiyalarni o'z ichiga oladi.

## ✨ Imkoniyatlar

- 🛍️ O'yinlarni ko'rish, qidirish, kategoriya va narx bo'yicha saralash
- 👤 Ro'yxatdan o'tish, kirish, profilni tahrirlash (ism, email, parol)
- 💳 Demo to'lov oynasi (karta ma'lumotlarini jonli formatlash bilan)
- 📚 Sotib olingan o'yinlar kutubxonasi va aktivatsiya kaliti
- ❤️ Sevimlilar ro'yxati (wishlist)
- ⭐ Reyting va sharhlar (faqat sotib olganlar uchun)
- 🏷️ Chegirmalar tizimi
- 🌐 Uch tilli interfeys: O'zbekcha, Русский, English
- ⚙️ Admin panel orqali o'yin, kategoriya va buyurtmalarni boshqarish

## 🛠️ Texnologiyalar

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
- **Ma'lumotlar bazasi:** SQLite

## 🚀 O'rnatish

\`\`\`bash
git clone https://github.com/7khsnbyvv/Gaming_store.git
cd Gaming_store
python -m venv venv
source venv/bin/activate
pip install django pillow
python manage.py migrate
python manage.py runserver
\`\`\`

Brauzerda `http://127.0.0.1:8000/` ni oching.
